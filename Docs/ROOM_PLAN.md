# 안방 구조·소품·그래픽 계획 (ROOM_PLAN)

2026-11-12 작성 (기획 세션, Opus 5.5). 입력: `Docs/ROOM_PLAN_BRIEF.md`, `Docs/DESIGN.md`, 레벨의 현재 배치(MCP 조회).
표시: **[사용자]** 는 사용자가 정한 것, **[제안]** 은 기획 세션의 기본값이라 구현하면서 바꿔도 된다.
구현: Sonnet 5.5 (medium). 에디터 조작은 `unreal-worker`, 블렌더는 `blender-worker`, 생성은 `gen-3d`.

## 0. 목표

사용자 피드백 [사용자]: "흰 방에 소품만 덜렁 있고 시점도 안 맞는다. 방을 크게 못 하면 **시야를 내리고 넓게 보이게**, 그리고 **방을 채우자**."

그래서 이 계획의 우선순위는 다음 순서다.
1. **시점과 크기 감각**: 눈높이, 시야각, 천장 높이, 소품의 실제 치수.
2. **방의 뼈대**: 벽·바닥·천장의 재질, 기둥, 문, 창.
3. **빛**: 이 방은 빛으로 정서를 전한다 (밤의 스탠드 vs 흐린 빛).
4. **채우기**: 소품을 더한다.

1~3은 생성 크레딧 없이 엔진 안에서 끝나고, 효과가 가장 크다. 4는 시간이 남는 만큼 한다.

정서 기준(DESIGN.md)을 그대로 따른다. 무언가를 넣을지 헷갈리면 "할머니가 위급한 방에서 이게 어울리나"를 묻는다.

## 1. 시점과 크기 [제안]

지금 상태: 카메라가 템플릿 마네킹의 `head` 소켓에 붙어 있어 눈높이가 서 있는 어른(약 165~170cm)이다. 캡슐 half height는 96(키 192), FOV는 기본값 90으로 추정된다. 시골 안방은 앉아서 사는 방이라 가구가 전부 낮고, 이 눈높이에서는 소품이 발밑에 깔려 휑해 보인다.

| 항목 | 지금 | 바꿀 값 | 이유 |
|---|---|---|---|
| 눈높이 (바닥에서 카메라) | 약 165~170 | **135cm** | 낮은 가구가 시야 가운데로 들어온다. 허리 숙인 손자 |
| 캡슐 | r34, hh96 | **r30, hh75** (키 150) | 문 높이 180을 지나가게. 캡슐 키 < 문 높이 |
| 시야각 (일반 FOV) | 90 (추정) | **95** | 넓어 보이게. 100 넘으면 가장자리가 늘어나서 피한다 |
| 걷기 속도 | 템플릿 기본 | **최대 200 안팎** | 좁은 방에서 천천히. 걸음이 빠르면 방이 작아 보인다 |
| 천장 아랫면 | z=260 | **z=240** | 실제 시골집 높이. 눈높이를 낮춘 만큼 천장도 내려야 비율이 산다 |
| 방 바닥 넓이 | 600×500 | **그대로** | "넓게"를 위해 줄이지 않는다. 대신 채운다 |

- 95로 바꾸는 값은 카메라 컴포넌트의 **`FieldOfView`**(월드 시야각)다. `FirstPersonFieldOfView`(70)와 `FirstPersonScale`(0.6)은 1인칭 팔 메시에만 쓰는 값이라 그대로 둔다 [기획 세션 판단].
- 카메라는 `head` 소켓 대신 캡슐에 붙이고 상대 Z로 눈높이를 정하는 쪽이 확실하다. 방식은 구현 세션이 정한다. PIE에서 카메라 월드 Z를 재서 135±5인지 확인한다.
- 헤드밥(걸을 때 흔들림)은 넣지 않는다 (DESIGN: 화면 흔들림 금지).
- 방 B도 같은 캐릭터라 따로 할 일은 없다. 천장 z=240은 방 B에도 똑같이 적용한다.

## 2. 방 A 평면도 [제안]

좌표는 방 A 기준이다 (방 B는 x+6000). 안쪽 벽은 x ±300, y ±250, 바닥 z=0. 위가 +Y다.

```
                        +Y 벽 (y=+250) : 창이 있는 벽
 x=-300 ┌───────────────────────────────────────────────┐ x=+300
        │ 기둥  시계    달력   [====창 x 40~160====]  기둥│
        │      (-170)  (-60)    가족사진 3개 (인방 위)   │
        │                 전화+방석     ┌────이불────┐ ⓛ스탠드
        │                 (-40,215)     │ 할머니 (100,195)│(255,215)
        │                               └────────────┘ ▣소반+주전자
   ▣TV장│                       요강 (−10,150)         (230,120)
   +TV  │                                          ┌──┐
 (-270,0)│ → TV 앞 도착점 (-180,0)                  │장│
   기둥 │                                          │롱│ (258,0)
        │                                          └──┘
        │          방석 2  라디오                      │
        │         (-60,-120)              반짇고리     │
        │    ★ 시작점 (-165,-150)         (180,-150)   │
        │ 기둥 [방문 x -210~-120]   약장(100, 벽)  궤(150,-190)
        └────┤          ├───────────────────────────────┘
             │ → 마루   │  -Y 벽 (y=-250). 아래 "마루와 부엌" 참고

평면도의 "전화+방석"은 전화기가 마루로 가므로 방석만 남긴다.
★ 시작점은 방문 바로 안쪽이고 yaw 85(대략 +Y 쪽)를 본다.

### 동선과 첫 화면

- **방문**: -Y 벽, x -210~-120 (폭 90, 높이 180). 창호 미닫이 문짝 한 짝이 열린 채 벽 쪽으로 밀려 있다 (DESIGN: 문은 처음부터 열려 있다). 문지방은 높이 5cm (캐릭터가 넘을 수 있는 높이).
- **창**: +Y 벽, x 40~160 (폭 120), 창턱 z=80, 윗변 z=170. 창호지 미닫이 두 짝. **할머니 바로 위에 있어서 결말의 새벽빛이 할머니에게 떨어진다** (DESIGN 결말 2).
- **TV**: -X 벽 가운데 (-270,0), TV장 위, +X를 향한다. 지금 위치 그대로 두고 높이만 TV장만큼 올린다 (z≈45).
- **할머니**: 지금 자리 (100,195) 그대로. 머리는 스탠드가 있는 +X 쪽으로 가정한다. 모델을 보고 반대면 소반과 스탠드를 반대편으로 옮긴다.
- **시작점 [제안]**: (0,0,100)에서 **방문 바로 안쪽 (-165,-150), yaw 85**로 옮긴다. 막 도착한 손자가 방을 가로질러 보는 첫 화면이 된다. 왼쪽에는 스탠드 빛 아래 누운 할머니와 창이, 오른쪽에는 구석의 TV가 푸르게 깜빡인다. 따뜻한 빛과 차가운 빛이 한 화면에 들어온다. FOV 95에서 둘 다 들어오는지 PIE로 확인하고 yaw를 맞춘다.
- **TV 앞 도착점**: 전환 뒤 서는 자리는 (-180,0) 근처, TV를 바라본다. 이 값은 `ACutTV`의 기존 설정을 따른다.
- **가운데를 비운다**: 방 가운데(대략 x -150~150, y -100~100)는 바닥만 둔다. 걸어 다닐 길이고, 장판이 보여야 방이 넓어 보인다. 소품은 벽을 따라 둔다.

### 마루와 부엌 (안방에 이어서 짓는다) [사용자: 이어서 짓는다 / 배치는 제안]

DESIGN의 흐름(안방 → 마루 → 부엌)대로 방문이 실제 마루로 이어진다. 방 B도 같은 구조를 x+6000에 복제한다.

```
 x=-620      x=-300                         x=+300
   ┌───────────┬──────────── 안방 ────────────┐  y=+250
   │           │                              │
   │  (안방 서쪽 벽 바깥, 비움)                 │
   │           │                              │  y=-250
   ├───────────┼──[방문 -210~-120]────────────┤  y=-270
   │   부엌    ⇆ 마루 (대청)                   │
   │ 흙바닥    │ 궤(마루 동쪽 끝), 전화기+방석   │

| 공간 | 범위 (방 A 기준, 안쪽) | 바닥 | 천장 | 놓는 것 |
|---|---|---|---|---|
| 마루 | x -300~300, y -570~-270 | `M_Maru` 판자 | 240, 서까래 대신 반자 (안방과 같은 재질) | 궤 (DESIGN: 극장판 마루의 잠긴 궤), 전화기와 방석 (마루 전화기 옆 메모), 앞벽(-Y)에 유리 미닫이 (밖은 밤의 마당. 검게 두고 달빛 Rect 하나) |

- 전화기와 달력은 지금 안방에 있다. **마루와 부엌으로 옮긴다** (DESIGN의 기록 위치). 안방 평면도의 "전화+방석" 자리는 비우거나 방석만 남긴다.
- 마루와 부엌의 구조물은 안방과 같은 규칙을 따른다: 기둥, 인방, 걸레받이, 문틀은 P0이고, 큐브와 같은 머티리얼을 쓴다. 벽지는 마루에서 `M_Wall_Upper` 하나만 쓴다 (안방보다 소박하게).
- 빛 (감독판): 마루는 앞 유리문의 달빛과 안방 방문에서 새는 스탠드 빛만 둔다. 부엌에는 천장의 백열전구 하나(2700K, 약하게)를 켜 둔다. 할머니가 끄지 않은 불이다. 극장판에서는 셋 다 흐린 회색빛 한 가지로 통일한다.
- 마루·부엌에 추가할 소품 (P1, 프롬프트는 §4 규칙대로):
  - 부뚜막 `hearth_stove`: `a low clay and stone kitchen hearth with a large black iron cauldron set into the top,`
  - 찬장 `cupboard`: `an old wooden kitchen cupboard with glass sliding doors and a few bowls inside,`
  - 소쿠리 `bamboo_basket`: `a shallow round woven bamboo basket,`
- **컷:** 11/13 12:00에 마루·부엌의 뼈대(바닥, 벽, 문 구멍)가 안 되면 안방만 남긴다. 방문 밖은 마루 띠 150cm와 막힌 벽으로 닫고, 궤·쌀독·달력·전화기는 안방 벽을 따라 옮긴다 (흐름 담당 세션에 알린다).

## 3. 벽·바닥·천장 방침 [제안]

결정: **엔진 큐브 + 월드 정렬(World Aligned) 절차적 머티리얼**로 간다. 생성형 3D로 통째로 뽑지 않고, 모듈 메시도 만들지 않는다.

- 이유: 큐브는 이미 있고 UV 작업이 필요 없다. 절차적이면 이음매가 없고 텍스처 크레딧도 들지 않는다. 방 B가 같은 머티리얼을 쓰니 한 번만 만들면 된다.
- 손으로 칠한 질감이 부족하면 P1에서 Gemini로 이음매 없는 타일 텍스처를 만들어 같은 머티리얼의 BaseColor에 곱한다. 이 텍스처는 들이는 즉시 `ASSETS.md`에 적는다. 절차적 버전이 기본이라, 텍스처가 실패해도 방이 망가지지 않는다.

## 8. 구현 세션이 확인할 것

- **가장 먼저:** 레벨에서 `Chest_A`의 `AcceptItemId`와 `TextId`를 읽는다. 약 아이템을 받는 대상(`Medicine.*` 텍스트)이면 메시를 소반으로 바꿔 머리맡으로 옮긴다. `AcceptItemId`가 비어 있거나 `Chest` 텍스트를 쓰면 장식용 궤다. 그러면 소반을 새 `ACutUseTarget`으로 두고, 궤는 DESIGN대로 마루 쪽으로 보낸다.
- `ACutTV`의 도착점이 월드 좌표인지 TV 기준 상대값인지 읽는다. TV장을 넣고 벽을 자른 뒤 도착점이 TV장이나 벽과 겹치지 않는지 PIE로 확인한다. PlayerStart를 옮겨도 전환 코드에 방 A 좌표가 박혀 있지 않은지도 같이 본다.
- 방 B는 방 A를 그대로 복제한다 (거울상으로 뒤집지 않는다). TV 속 그림은 미리 찍은 정지 화면이라 배치가 같아도 문제없다 [기획 세션 판단].
- `grandma_blanket` 모델의 베개가 어느 쪽인지 확인한다. 소반·스탠드의 위치가 따라간다.
- BP_FirstPersonCharacter가 C++ 카메라 값을 덮어쓰는지 확인한다 (MCP로는 읽지 못했다).
- 레벨의 y≈18000~22000에 템플릿 테스트 지오메트리 약 25개와 방 A 안의 `Brush_1`이 남아 있다. 쓰지 않으면 지운다 (사용자에게 한 번 묻는다).
- 방 B의 기존 소품(영정, 향로, 흰 천 등) 위치를 §4 차이 표에 맞춘다.
