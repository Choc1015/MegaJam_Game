# 방 구조·소품 기획 브리프 (기획 세션용)

작성: 2026-11-12. 목적: "방이 더 진짜 방처럼 보이게" 하는 구조물·소품 목록과 배치도를 확정한다. 구현은 이후 Sonnet 세션이 한다.

## 현재 상태

- 이름: **감독판 = 지금의 집(방 A, x≈0, 시작, 할머니 계심)**, **극장판 = 끝난 집(방 B, x≈6000, TV 너머)**.  4판(11/12 23:05): 플레이어는 손주이자 영화감독이고, 방 B는 그가 이미 공개한 자기 영화다. 소품으로만 암시한다 (`Docs/ROOM_PLAN.md` §10). 방 B는 방 A의 x+6000 복제. 설계 기준은 `Docs/DESIGN.md`.
- 방 치수(cm): 바닥 윗면 z=0, 안쪽 벽 x ±300, y ±250, 천장 아랫면 z=260. 벽·바닥·천장은 지금 **단색 박스(그레이박스)**. 이게 가장 큰 부족함.
- 모델 18개 생성·배치 완료 (Tripo H3.1, `SourceArt/Generated/`, 언리얼 `/Game/Art/Generated/<이름>/SM_*`). 목록과 출처는 `ASSETS.md`. 소품: 장롱, 약장, 벽시계, 달력, 전화, 스탠드, 화장대류, 이불, 영정, 향로, 흰 천, 스툴, 궤, 수첩, 약봉지, 침대류, CRT TV 등.
- 방 A/B는 같은 소품을 공유하되 방 전용 소품이 다르다 (A: 이불 펴짐, B: 이불 개어짐, 영정·향로·흰 천).
- 게임플레이 액터(`ACutTV`, `ACutInteractable`, `ACutUseTarget`, `ACutPickup`)는 그대로 둔다. 코드는 `Source/WhatWasCut/Cut/`.

## 부족한 점 (사용자 판단)

방이 진짜 방 같지 않다. 벽·바닥·천장이 밋밋하고, 창문·문 같은 구조물이 없고, 생활감이 부족하다.

## 기획 세션이 정할 것

1. 구조물 목록: 창문, 방문, 문틀, 몸채 기둥·서까래, 걸레받이, 천장 조명 등 무엇을 넣을지 (한국 시골집 안방 기준).
2. 벽·바닥·천장 처리: 텍스처 타일(흙벽/회벽, 장판/마루, 천장)로 갈지, 모듈 모델로 갈지. 타일링이 필요해 생성형 3D로 통째로 뽑지 않는다.
3. 추가 소품 목록과 우선순위 (요강, 방석, 베개, 약탕기, 호롱, 화장대, 병풍 등). 감독판/극장판에서 어떻게 달라지는지(생활의 흔적 vs 정리된 흔적).
4. 방 A의 평면 배치도 (문·창·TV·침대 위치, 동선, 플레이어 시작점 (0,0,100)).
5. 일정에 맞춘 컷: 11/15 10:59 기능 동결. 모델이 늘수록 일정이 빠듯하다. "압박이 오면 뺀다".

## 지킬 제약

- 3D 생성 프롬프트 끝에 CLAUDE.md의 아트 스타일 한 줄을 그대로 붙인다. 타인 IP 금지.
- 모델 하나에 물체 하나. 폴리 예산: 소품은 현재 약 2.6만~3만 tris. 10k 미만 목표는 미달 상태.
- Tripo 웹 크레딧 약 4000 (40/개), CLI 1000(20/개), Meshy 1110.
- 감독판/극장판의 차이는 같은 모델에 후처리로 낸다 (감독판: 따뜻하고 선명 / 극장판: 색 빠진 푸른빛, 필름 노이즈, 검은 띠). 극장판용 별도 모델은 만들지 않는 것이 원칙, 방 전용 소품만 예외.
