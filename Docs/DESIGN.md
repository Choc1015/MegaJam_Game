## 한 문장

**할머니의 병이 잘려 나간 채 끝나 버린 "극장판"과 아직 편집 중인 지금을 낡은 TV로 오가며, 기록을 맞춰 병을 알아내고 약을 가져와, 결말이 다른 "감독판"을 완성한다.**

## 정서 기준 [사용자]

**이미 늦어 버린 세계의 먹먹함을 안고 돌아와, 아직 늦지 않은 세계에서 해낸다.**

게임의 모든 것(전환, 소리, 색, 글, UI, 모델)은 이 한 줄에 맞춘다. 맞지 않으면 뺀다. 무언가를 넣을지 헷갈리면 "할머니가 위급한 방에서 이게 어울리나"를 묻는다.

## 주제와의 연결

감독판은 "이미 공개된 판을 감독의 뜻대로 다시 편집한 판"이다. 이 게임에서 **잘린 것은 할머니의 병**이고, **감독은 플레이어**다. 극장판은 병이 잘려 나간 채 공개돼 끝난 판이다. 플레이어는 지금의 집에 흩어진 잘린 장면(증상의 기록)을 되찾아 결말을 다시 편집한다. 약을 드려 결말이 바뀌는 순간, 지금의 세계가 감독판이 된다.

| | 감독판 (지금, 편집 중) | 극장판 (이미 끝난 세계) |
|---|---|---|
| 무엇인가 | 아직 편집 중인 원본 필름. 잘린 장면(증상의 기록)이 집 안에 그대로 남아 있다. 할머니도 손자도 괜찮은 줄 안다 | 이미 공개돼 끝난 판. 병은 잘려 나가고(병명이 번져 읽을 수 없다) 결말만 남았다 |
| 할머니 | 누워 주무신다. 병을 대수롭지 않게 넘겼다 | 안 계신다. 오늘 밤 03:40에 돌아가셨다 |
| 바꿀 수 있나 | 아직 편집 중이라 바꿀 수 있다 | 공개된 필름이라 바꿀 수 없다. 끝까지 그대로 남는다 |
| 남은 기록 | "전"의 기록: 흩어진 증상 메모, 달력 | "후"의 기록: 뒤늦은 검사지, 영정, 정리된 유품, 드시지 못한 약 |
| 플레이어가 느낄 것 | 아직 할 수 있다는 희망과 다급함 | 먹먹함 |

## 핵심 루프 [사용자]

1. 한쪽 판에서 기록과 물건을 살펴본다.
2. 안방의 TV로 다른 판에 건너간다. 손에 든 물건은 따라온다.
3. 두 판의 기록을 맞춰 추리한다. **한쪽 판의 기록만으로는 답이 나오지 않는다.**
4. 필요한 물건을 가져와 쓴다.

걷고, 살펴보고, 읽고, 줍고, 쓴다. 전투, 점프, 시간 제한, 실패는 없다.

## 흐름 [사용자 승인]

집 하나(안방, 마루, 부엌), 레벨 하나. 플레이어는 할머니가 아프다는 소식에 찾아온 손자다. 모습은 나오지 않는다.

1. **감독판, 안방.** 할머니가 힘겹게 주무신다. 시계가 똑딱인다. 수첩에 "요즘 숨이 찬다. 나이 탓이지." 구석의 TV에 이 방이 나오는데, 화면 속에는 할머니가 없고 이불이 개어져 있다.
2. **극장판, 안방.** TV를 만지면 건너간다. 개어 놓은 이불, 영정, 향. 시계를 살펴보면 **03:40에 멈춰 있다** [사용자]. 검사지는 병명이 번져 읽을 수 없고 "평소 증상을 알았다면 일찍 발견했을 것"이라는 소견만 남았다. 이쪽 TV에는 할머니가 누워 계신 지금의 방이 나온다.
3. **극장판, 마루.** "유품"이라 적힌 잠긴 궤. 열쇠가 없다.
4. **감독판, 부엌과 마루.** 할머니가 남긴 증상 메모들, 그리고 "귀한 건 쌀독에." 쌀독에서 열쇠를 찾는다. (극장판의 쌀독은 비어 있다.)
5. **극장판, 마루.** 열쇠로 궤를 연다. 드시지 못한 약봉지가 셋, 봉투마다 "이런 증상에"가 적혀 있다. 감독판에서 모은 증상 셋이 전부 맞는 것은 하나다.
6. **감독판, 안방.** 약을 머리맡에 둔다. 틀린 약이면 "수첩의 증상과 맞지 않는다"만 뜨고, 다시 가서 고르면 된다.

### 결말 [사용자 승인]

1. 시계가 **03:40을 지나간다.** 멈추지 않고 계속 똑딱인다. 음악은 없다. 이때 구석에 작은 글자 `Director's Cut`이 소리 없이 2초 떴다 사라진다 (3판에서 추가. 그전에는 "글자도 없다"였다).
2. 할머니 숨소리가 고르게 바뀌고 창으로 새벽빛이 든다.
3. TV에는 여전히 빈 방(극장판)이 나온다. **플레이어가 직접 TV를 끈다.**
4. 꺼진 화면 위로 제목이 조용히 뜨고 크레딧.

### 기록 목록 [제안]

**초안이다.** 큰 틀(위의 흐름)은 확정이고, 아래 추리의 구체 내용은 구현하면서 다른 세션에서 다듬기로 했다 [사용자, 14:55]. 다듬을 때 지킬 것: 한쪽 판의 기록만으로는 답이 안 나온다, 실패는 없다, "정서 기준"에 맞는다.

## 통일 기준 (모든 요소를 정서에 맞춘다)

| 요소 | 감독판 (지금) | 극장판 (끝난 세계) |
|---|---|---|
| 빛 | 밤. 스탠드의 따뜻한 노란빛. 결말에만 새벽빛 | 같은 방, 색이 빠진 푸른 회색. 시각을 알 수 없는 흐린 빛 |
| 화면 | 꽉 찬 화면, 깨끗함 | 위아래 검은 띠, 필름 입자, 가장자리 어두움 |
| 소리 | 시계 똑딱, 할머니 숨소리, 먼 풀벌레, TV의 낮은 잡음 | 거의 무음. 시계 소리가 없다. TV에서만 희미하게 저쪽 시계 소리 |
| 사물 | 생활의 흔적: 펴진 이불, 켜진 불, 쓰던 물건 | 정리된 흔적: 개어 놓은 이불, 흰 천을 덮은 가구, 비어 있는 자리 |

공통:

- **음악:** 없다. 결말 제목에만 짧은 선율 하나 (없어도 된다).
- **전환:** TV 화면이 한 줄로 접히며 꺼졌다가 다시 켜진다. 1초 안팎. 소리는 낮은 잡음과 딸깍 한 번.
- **완료 신호:** 글자를 쓰지 않는다. 소리(숨소리, 시계), 빛, 사물의 변화로만 알린다.
- **영화 표현은 조용한 것만** [사용자 승인]: 극장판의 검은 띠와 입자. 구석의 작은 글자는 두 번만, 소리 없이 2초씩: 극장판으로 처음 건너갔을 때 `Theatrical Cut`, 결말에서 시계가 03:40을 지날 때 `Director's Cut`. 시작할 때는 아무 글자도 없다 (3판).
- **UI:** 화면 가운데 작은 점 하나. 상호작용할 수 있을 때만 한 단어. 목표 표시, 체크리스트, 알림 없음.
- **글:** 한 번에 한두 줄. 화면 아래 자막 위치, 작은 글씨, 천천히 나타나고 사라짐.
- **모델:** 두 판이 같은 모델을 쓴다. 차이는 보이기/숨기기와 후처리로만 낸다. 스타일 문구는 `CLAUDE.md`의 "아트 스타일" 절.
- **넣지 않는 것:** 슬레이트, "컷!", 팡파르, 점수, 밝은 효과음, 화면 흔들림, 튀어나오는 알림, 감독 코멘터리.

## 만들 것 (MVP)

만드는 순서대로.

1. 1인칭 이동과 시점.
2. 판 상태와 물체별 표시 (`감독판만 / 극장판만 / 둘 다`로 보이기와 충돌을 켜고 끈다). 감독판 = 지금의 집, 극장판 = TV 너머의 끝난 집. 3판에서 이름이 바뀌었으니 코드의 이름도 이 뜻에 맞춘다.
3. 상호작용 (`E` 하나): 살펴보기(한 줄), 읽기(기록), 줍기, 쓰기.
4. 들기: 한 번에 하나. 다른 물건을 집으면 들고 있던 것은 원래 자리로 돌아간다.
5. **TV 전환** [사용자]: 안방에 한 대. 만지면 다른 판의 같은 자리(TV 앞)로 건너간다. 화면 속 그림은 미리 찍어 둔 정지 화면.
6. 안방의 두 판을 회색 상자로 → 마루, 부엌 → 궤, 열쇠, 약봉지 셋 → 결말.
7. 판별 후처리 2벌과 소리.
8. 제목 화면, 크레딧, 다시 시작.

**[제안]**
- 조작: WASD + 마우스, `E` 상호작용, `Esc` 메뉴. 전환 키는 없다.
- 방문은 처음부터 열려 있다. 길잡이는 TV의 깜빡임과 소리가 한다.
- 시계의 바늘은 진행에 맞춰 움직인다 (시작 23:50쯤 → 결말에 03:40 통과). 실제 제한 시간은 없다.
- 할머니는 애니메이션 없는 누운 정지 모델 하나. 숨은 소리와 이불의 아주 작은 움직임으로만.
- 게임 내 글은 영어, 짧은 문장. 글은 데이터로 빼서 교체할 수 있게 한다.
- 가제: *What Was Cut*. 제목과 팀명은 사용자가 정한다.
